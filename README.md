# E-Commerce Public Dataset Dashboard ✨

Data analysis project on the E-Commerce Public Dataset (Olist, Brazil). It covers delivered orders from January 2017 to August 2018 and answers two questions:

1. How much higher is the median order value of multi-item orders compared with single-item orders, and which product categories appear most often in multi-item orders?
2. What percentage of customers are repeat customers, and how much more do they spend than one-time customers?

The analysis also includes RFM analysis, customer segmentation based on RFM scores, and geospatial analysis.

The deployed dashboard link is in `url.txt`.

## Project Structure

```
submission
├───.streamlit
│   └───config.toml         # Dashboard theme
├───dashboard
│   ├───dashboard.py        # Entry point: page setup, filters, KPIs, tabs
│   ├───views.py            # One render function per tab
│   ├───components.py       # Reusable UI pieces (header, KPI cards, callouts, cards)
│   ├───charts.py           # Altair chart builders
│   ├───analytics.py        # Data loading, filtering, and aggregates
│   ├───theme.py            # Color tokens shared by charts and CSS
│   ├───style.css           # Page styling
│   └───main_data.csv       # Cleaned data used by the dashboard (generated by the notebook)
├───data                    # Raw dataset files used in the analysis
├───notebook.ipynb          # Full analysis: questions, wrangling, EDA, visualization, conclusion
├───README.md
├───requirements.txt
└───url.txt                 # Link to the deployed Streamlit dashboard
```

## Setup Environment - Anaconda

```
conda create --name main-ds python=3.12
conda activate main-ds
pip install -r requirements.txt
```

## Setup Environment - Shell/Terminal

```
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
```

Python 3.11 or newer is required (pandas 3.x).

## Run the Notebook (optional)

```
pip install notebook
jupyter notebook notebook.ipynb
```

Run all cells from the `submission` folder. The notebook reads the files in `data/` and writes `dashboard/main_data.csv`.

## Run the Streamlit App

From the `submission` folder:

```
streamlit run dashboard/dashboard.py
```

The dashboard opens at `http://localhost:8501`. Use the sidebar to filter by purchase date and customer state. The tabs cover the monthly overview, basket size, customer retention, RFM segments, and geography.
